# Notebooks

`analysis.ipynb` is the long-form, narrative complement to the dashboard. Where
the dashboard is browseable, the notebook walks through all six experiments as a
story: hypothesis → method → results → takeaway (spec §7).

`scripts/export_notebook.py` renders `analysis.ipynb` to `analysis.html` so it
is viewable directly on GitHub. CI verifies the HTML is up to date.
